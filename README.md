# Mini SIEM Log Analyzer

A simple Python-based log analyzer for detecting suspicious login activity.

## About the Project

This project analyzes login logs and looks for repeated failed login attempts. It is a beginner-friendly cybersecurity project created to practice Python and basic security concepts.

## Features

- Detect repeated failed login attempts
- Identify suspicious login activity
- Count failed attempts
- Display useful log information
- Simple command-line interface

## Technologies Used

- Python 3
- Regular Expressions
- File Handling

## How to Run

```bash
git clone https://github.com/srabontics26/mini-siem-log-analyzer.git
